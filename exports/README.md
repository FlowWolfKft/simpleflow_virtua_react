# Simple Flow logócsomag

Végleges irány: négyszögspirál, iránykövető rózsaszín–lila–kék gradient, Plus Jakarta Sans wordmark.

## Fájlok

- `simpleflow-logo-outlined.svg`: teljes logó alcímmel, a szöveg görbévé alakítva; ez a legbiztonságosabb vektoros változat.
- `simpleflow-logo-compact-outlined.svg`: kompakt szólogó fejléc és kisebb felületek számára.
- `simpleflow-logo-mono-outlined.svg`: egyszínű vektoros változat.
- `simpleflow-logo-2400.png`: nagy, átlátszó hátterű PNG.
- `simpleflow-logo-compact-1600.png`: kompakt, átlátszó hátterű PNG.
- `simpleflow-submark.svg` és `simpleflow-submark-1024.png`: önálló négyzetspirál jel.
- `simpleflow-favicon.svg`, `favicon-512.png`, `favicon.ico`: favicon-változatok, kizárólag a submarkkal, felirat nélkül.

Az `outlined.svg` fájlok használatához nincs szükség telepített betűtípusra.
